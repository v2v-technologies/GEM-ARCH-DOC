Step-by-step system migration guide · v2v.ca

01
Create a Fresh System
Make sure the system you're using is brand new. Do not reuse any previously tested or used systems. Skip any cleanup steps.
Use a new, clean system only. No reuse. No cleanup required.
Critical
02
Download GEM-Archive (Latest Version)
Download the latest version of gem-archive from the official GitHub releases page.
Download github.com/v2v-technologies/GEM-ARCHIVES/releases
03
Open GEM-CAR Convert Tool
Navigate to the newly created system and open the GEM-CAR CONVERT tool from within the interface.
Tool Access
04
Copy URL & One-Time Use Key
Inside the GEM-CAR Convert tool, locate and copy both the URL and the One-Time Use Key. You'll need these in the next step.
Copy Credentials
05
Open GEM-Archive & Paste Credentials
Open the gem-archive application. Paste the URL and the One-Time Use Key in their respective fields.
Paste Credentials
06
Set Your Password and sysID
Obtain the password by contacting yahya@v2v.ca, then set it in the application.
Authentication
07
Select the Full .BAK File
Browse and select the complete .bak backup file you want to migrate. Make sure to select the full file, not a partial one.
File Selection
08
Select Transfer Options & Region
Choose what data you want to transfer. Then set the default Country and Province from the provided dropdowns.
Configuration
09
Click Transfer & Wait
Click the Transfer button and wait for the process to complete. Do not close or interrupt the application during the transfer.
Do not close the application while transfer is in progress.
10
Log Completion in Google Sheets
Once the transfer is done, open the tracking spreadsheet and fill in the System ID, Date, and Done By fields.
Open Tracking Spreadsheet Final Step
